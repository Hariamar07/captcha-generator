CAPTCHA Generator 🔐
This is a simple CAPTCHA generator built using HTML, CSS, and JavaScript. It dynamically generates random CAPTCHA codes to help prevent automated form submissions. The project demonstrates basic front-end development techniques, DOM manipulation, and form validation logic.

✨ Features

Random CAPTCHA code generation

CAPTCHA refresh option

Input validation to match CAPTCHA

Clean and responsive UI

🌐 Technologies Used

HTML5

CSS3

JavaScript
